## Getting Started

1. Run `npm install`
2. Run `npm run dev`

## Type-checking

`npx tsc --noEmit` should report no errors. Run this before pushing — a clean check is a good sanity signal that nothing is silently broken.

## Deploying (Round 3: public, working link)

This is a static Vite build, so any static host works. Two zero-config options are wired up already:

**Vercel**
1. Import the GitHub repo at vercel.com/new
2. It auto-detects Vite; `vercel.json` is already set with the build command and output directory
3. Deploy — you get a public `*.vercel.app` link

**Netlify**
1. "Add new site" → "Import an existing project" → pick the repo
2. `netlify.toml` already sets the build command and publish directory
3. Deploy — you get a public `*.netlify.app` link

**Before submitting:**
- Put this project inside a folder named exactly as your team number in the shared GitHub repo (per the rules — a mismatch here is on the team, not the organizers)
- Click through every nav link and both CTA buttons on the deployed link itself, not just localhost, to confirm nothing 404s
- Test on a phone or with dev tools' device toolbar — the mobile nav menu and all sections are responsive, but always worth a last check on the real deployed link
